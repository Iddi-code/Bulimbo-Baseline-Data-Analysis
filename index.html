Data quality & interpretation

The dashboard contains all 161 indexed farmer records reconstructed from the Bulimbo baseline export. Similar village spellings are retained as they appear in the source rather than silently merging them.

Source-level anomalies retained: one farmer record has a blank current-infestation/severity response, and a small number of records contain repeated/combined source text. The dashboard does not invent missing values. Overall headline KPIs use the validated baseline figures already reported for Bulimbo; filtered village KPIs are calculated directly from the embedded farmer-level records.

Public GitHub privacy: farmer phone numbers are intentionally not displayed in this public dashboard. Names, village, group and baseline indicators are included to support village-level analysis.
